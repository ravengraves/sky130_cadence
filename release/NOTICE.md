# NOTICE

Cadence-ready files for SkyWater's open sky130 standard cells (`sky130_fd_sc_hs`), generated by the
`sky130.py` scripts of this repository. Regenerate with `python3 sky130.py all` and
`python3 sky130.py release`.

## Changes to upstream files (diffs in `patches/`)

- `tech/sky130_fd_sc_hs_innovus.tlef`: cut layer `licon` added after `pwell`. Innovus 20 rejects
  the upstream tech LEF otherwise (IMPLF-121).
- `tech/sky130_fd_sc_hs_cells.lef`: `FOREIGN` of `diode_2` and `fill_diode_2/4/8` set to the
  macro name. The pre-release `scs8hs_*` names left those cells without geometry in streamed GDS.
- `tech/*.lib.gz`: Liberty written from the upstream JSON timing views (gzip); CCS-noise groups
  dropped, except in `tech/ccs/*.lib.gz` (CCS-noise corners, written by `sky130.py ccs-libs`).
- `spectre/models/fd_pr/`: transistor subcircuit parameters moved onto the `.subckt` line and
  `{expr}` changed to `'expr'` so Spectre accepts them; only the 1.8 V transistor families.
- `spectre/netlists/`: numbers such as `1.12e+06u` rewritten as `1.12`, which Spectre reads correctly.
- `tech/gds/sky130_fd_sc_hs__xor3_1.gds` and its LEF OBS: an internal met1 strap re-routed over
  input pin B, which it covered (no router access; shorts in routed designs). Same devices and
  nets; `patches/cell-fixes.txt` lists the shapes.

## Generated by this repository (MIT, `LICENSE`)

`cadence/` (Genus/Innovus/MMMC setup), `pegasus/` (DRC deck written from SkyWater's periphery
rules; LVS deck written from SkyWater's layer definitions), `mos/` (generated transistor
layouts), `characterization/` (Spectre sweeps), `quantus/` (layer setup, options),
`spectre/extracted/` (Quantus netlists of every cell), `library/` (library CDL, merged GDS,
flat Verilog models, Virtuoso OA layout library), `abstract/` (LEF from the Virtuoso Abstract
Generator), `examples/`, `GPDK045_COMPARISON.md`.

## Not included

Nothing from the Cornell C2S2 SKY130_PDK, which has no license. This repository has its own DRC
and LVS decks and a transistor generator; `python3 sky130.py download --cornell` fetches the
Cornell files for private comparison only.
