# sky130_fd_sc_hs for Cadence, release 2026.11.18

Cadence views and signoff decks for SkyWater's open 130 nm high-speed standard-cell library
`sky130_fd_sc_hs` (1.8 V, 390 cells), plus a second library (OSU 18-track high-speed cells).
Everything was generated by the `sky130.py` scripts of the source repository or copied unchanged
from an Apache-2.0 source; `NOTICE.md` lists the sources, pinned commits, licenses and every change
to upstream files. This repository's own files are MIT-licensed (`LICENSE`); upstream files keep
their Apache-2.0 license (`licenses/`). Paths inside are relative, so the folder works wherever it is unpacked.

Validated with Genus 25.15, Innovus 20.16, Pegasus 25.10, Quantus 25.1, Spectre 25.1 and
Virtuoso/Abstract IC25.1. Innovus 20 needs an OpenAccess older than Virtuoso 25's: set `OA_HOME`
for Innovus only.

## Quick start (paths relative to this folder)

Check the files: `sha256sum -c MANIFEST.sha256`

Genus:

```tcl
source cadence/genus_fdsc.tcl
fdsc_read_libs ss_n40C_1v60_ccsnoise   ;# slowest corner; or ss_150C_1v60, tt_025C_1v80_ccsnoise, ...
read_hdl my.v; elaborate my_top
fdsc_dont_use
read_sdc my.sdc
syn_generic; syn_map; syn_opt
write_hdl > my_netlist.v
```

Innovus: `examples/smoke/innovus.tcl` is a complete, tested flow (floorplan, power, well taps,
placement, CTS, routing, Quantus RC, fillers, GDS stream-out with the cell layouts merged).

Pegasus:

```sh
pegasus -drc -dp 4 -gds my_top.gds -top_cell my_top pegasus/sky130_full.pvl
pegasus -lvs -gds my_top.gds -top_cell my_top -source_cdl my_top.cdl -source_top_cell my_top \
        pegasus/sky130_lvs.pvl
```

For full-chip LVS, convert the routed Verilog to CDL that includes `library/sky130_fd_sc_hs.cdl`,
leave out the device-free fill and tap cells and make the supply nets ports (`sky130.py lvs-block`
in the source repository does this).

Virtuoso: start in `virtuoso/` (or `INCLUDE virtuoso/cds.lib`) for the `sky130` technology
library, `sky130_mos` PCells and the `sky130_fd_sc_hs` cell library.

Spectre: `cd spectre && spectre inverter_ss.scs`.

## Known limits

- One nominal RC corner (no public process-variation data for the sky130 metal stack).
- No fill deck (SkyWater's density rules for this stack are recommendations only).
- LVS covers MOS devices, the antenna diode and metal shorts; no resistors, capacitors or bipolars.
- Standalone cells report block-level well/implant enclosure results that abut away in rows.
- `sky130_fd_sc_hs__xor3_1` carries a metal-1 change so that its input B can be routed
  (same devices and nets; `patches/cell-fixes.txt`).
